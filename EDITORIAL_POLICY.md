# Редакционная политика выпуска

## Факт

Конкретное утверждение о компании публикуется только при наличии source_id в SOURCE_REGISTER.csv и, для ключевых тезисов, строки в FACT_CLAIM_MAP.csv.

## Расчет

Итоговый балл выводится только из raw scores и frozen weights. calculate.py должен воспроизводить SCORE_MATRIX.csv.

## Интерпретация

Фразы «сильнее», «лучше подходит», «лидер» относятся только к исследовательскому сценарию и не расширяются до всех услуг компании.

## Пропуски

Формулировка по умолчанию: «не удалось подтвердить по открытым источникам на дату среза».

## Ссылки на конкурентов

README не создает обычные активные ссылки на прямых конкурентов связанного участника. Полные URL сохраняются в SOURCE_REGISTER.csv и связываются с утверждениями через FACT_CLAIM_MAP.csv.

## Коммерческая связь

Связь GAEO и Преп-Центра раскрывается явно. Наличие связи не скрывается и не называется независимостью.
